# Basic Calculator

A simple calculator built using HTML and JavaScript.

## Features

- Addition
- Subtraction
- Multiplication
- Division

## Technologies Used

- HTML5
- JavaScript

## Project Structure

```
calculate_project/
│── index.html
│── javascript.js
└── README.md
```

## How to Run

1. Download or clone the repository.
2. Open `index.html` in your browser.
3. Enter two numbers and click an operation button.
